# Data Engineering Toolbox (Flavio Christofolo)

Repositório centralizado para estudos, automações e pipelines de Engenharia de Dados.

## 🛠 Stack Tecnológica
- **Linguagem:** Python 3.x
- **Manipulação de Dados:** Pandas
- **Bancos de Dados:** PostgreSQL, SQLite
- **Automação:** Cron, GitHub Actions
- **Ambiente:** Docker, Linux (CLI-first)

## 📁 Estrutura do Projeto
- `scripts/`: Scripts ETL e automações em Python.
- `notebooks/`: Exploração de dados e prototipagem Jupyer.
- `sql/`: Queries, DDLs e scripts de migração.
- `dbt/`: Modelagem de dados (opcional).
- `data/`: Armazenamento local de arquivos (Raw/Processed).

## 🚀 Como começar
1. Crie o ambiente virtual: `python3 -m venv venv`
2. Ative: `source venv/bin/activate`
3. Instale dependências: `pip install -r requirements.txt`
